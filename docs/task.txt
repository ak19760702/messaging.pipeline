Реализовать на Java небольшое приложение, которое обсуждается ниже.
Сообщения приходит из какого-нибудь брокера сообщений, например tibco.
Пусть сообщения приходят со скоростью t1, далее слобщение обрабатывается со скоростью t2, причем t2>t1. 
После обработки сообщение снова надо отправить, не важно куда, пусть будет другая очередь. 
И скорость отправки опять пусть будет t1. 
Порядок сообщений не должен меняться, то есть с сохранением порядка.

Входную очередь можно проэмулировать json-файлами в одном каталоге, выходную – файлами в другом каталоге
Входная папка In, выходная папка Out.
